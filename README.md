# Computer Engineering Projects Portfolio

A collection of hardware-software integration, embedded firmware, and system automation projects completed during my Computer Engineering coursework at the University of Texas at Dallas and personal time.

## 📂 Included Projects

### 1. Motor Fan Controlling System
*   **Technologies:** C++, Tinkercad, Arduino Uno, L293D H-Bridge, IR Sensor
*   **Description:** Firmware and simulated circuit design for an IR-controlled cooling fan system, utilizing PWM for dynamic speed modulation.

### 2. Automated Light Sensor and Calibration System
*   **Technologies:** C++, Arduino IDE, Breadboard Circuitry, Photo-resistors
*   **Description:** Embedded software logic to analyze analog inputs from environmental light sensors and trigger automated physical responses.
