# Computer Engineering Projects Portfolio

A collection of hardware-software integration, embedded firmware, and system automation projects completed during my Computer Engineering coursework at the University of Texas at Dallas and personal time.

📁 **Included Projects**

### 1. Motor Fan Controlling System
* **Technologies:** C++, Tinkercad, Arduino Uno, L293D H-Bridge, IR Sensor
* **Description:** Firmware and simulated circuit design for an IR-controlled cooling fan system, utilizing PWM for dynamic speed modulation.

### 2. Automated Light Sensor and Calibration System
* **Technologies:** C++, Arduino IDE, Tinkercad, Breadboard Circuitry, Photoresistors (LDR), 16x2 LCD.
* **Description:** Developed embedded C++ software to process analog environmental light data and trigger automated physical responses. Implemented state-toggle edge-detection logic utilizing internal pull-up resistors for a manual override mode. Successfully modeled physical hardware constraints and validated the circuit in Tinkercad, featuring real-time system diagnostics displayed on a 16x2 LCD.

### 3. Weather Card Dashboard
* **Technologies:** Python, Tkinter, OpenWeatherMap API, MySQL, Threading, GUI Development
* **Description:** Developed a modern, multi-threaded desktop GUI program featuring live API data fetching, asynchronous background workers to prevent interface freezing, and automated MySQL database logging. Integrated smart duplicate-conversion logic, interactive sorting/filtering options, granular record management with keyboard shortcuts, and inline ghost-text auto-completion for major cities.
